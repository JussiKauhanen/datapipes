# datapipes · landscape

A fresh angle on the same data: everything on one screen. Uses the same engine and data as the demo.

- **Landscape:** areas as boxes, contracts as cards, checkpoints as tiles in the order a message passes them.
- **Grid:** contracts as rows, systems as columns. Read down a column to see everything that depends on one system; click the heading for the impact list.
- **Colour by:** status, security level of the data leaving each system, or owning team. Untick legend items to fade them.

Open at `http://localhost:8000/landscape/` or `/datapipes/landscape/` on GitHub Pages.
