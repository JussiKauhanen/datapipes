Every system in a pipeline sends one small event each time it runs. Put those events side by side and three questions answer themselves: what flows where, where it broke, and who to call.

The event every system sends

Same shape at every stage. The owner is not in it: it is looked up from the system register by system_id, so the event stays small and ownership changes in one place.


      

        

          
FieldWhat it says

          
            
system_id, system_nameWho is reporting.

            
stageWhere in the pipe: source, integration, dynamics, apps or analytics.

            
flowWhich data flow, and so which data contract, this run belongs to.

            
sourceThe system it got the data from. This links the steps into a chain. Empty for a source system.

            
statusok or failed. The platform adds late, waiting and blocked itself.

            
dateWhen the run finished. No event for too long means the step is late.

            
security_levelHow secret the data is as it leaves this system. The next system must be cleared for that level.

            
messageOptional. One line on what went wrong.

Security levels

    
Each system is cleared up to a level. Data above it is stopped at the door, and the sender is the one who fixes it.
